# GPU vs CPU verification, 2026-11-13

Method: fixed seed, GPU build against a CPU build of the same compiler, observables compared with
`docs/gpu/scripts/defect/compare.py` (max deviation relative to the file maximum); configurations
(`confout_0`) and acceptance compared exactly. Short runs: they check equal-time and tau
observables and configuration identity, not long-run statistics.

| Backend | Host, compiler | Source | Cases | Max deviation | confout | Hang |
|---|---|---|---|---|---|---|
| NVIDIA | `maksim` RTX 4060 (cc89, `ALF_GPU_CC=cc89`), nvfortran 25.5 | `gpu-port` 5563e32e, `gpu-port-unified` 14935409 | L = 6, 12; Mz T/F; Checkerboard F/T; standard and submatrix; plus 8 stock-length runs per branch; 5 defect runs (`ham_h0 = 1`) on unified | Mz=F <= 5e-14; Mz=T <= 1.45e-11; defect Mz=F 2.3e-15, Mz=T 1.1e-11 | identical (58/58) | none |
| Intel | SuperMUC-NG Phase 2, Max 1550, ifx 2025.1.1 (job 560974) | `gpu-port-unified` 14935409 | L = 6, 12; Mz T/F; Checkerboard T; standard, submatrix (N_delay 0, 8) | Mz=F <= 4.3e-14; Mz=T 8e-12 (L=6), 1.8e-10 (L=12, SpinXY_eq) | identical (10/10) | none |
| AMD | `amd` MI210, gfortran 14 + amdgcn offload | `gpu-port-unified` deb65a7c | L = 12; Mz T/F; Checkerboard T (and F as control); standard | Mz=F 6.7e-13; Mz=T 5e-11 (small entries up to 3e-10, same with Checkerboard F) | identical | none |

Mz = T is the ill-conditioned case: on Intel and AMD it reaches 1e-10 to 3e-10 with identical
configurations and identical acceptance, independently of the checkerboard setting (rounding,
not a defect; the cause is not established further).

`$SCRATCH/mgr_cb/`, `amd:~/amd/work/cb12/`.
