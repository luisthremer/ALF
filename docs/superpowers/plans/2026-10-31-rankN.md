## Global Constraints
- Default (`Sequential_scheme = "standard"`) byte-identical to baseline `f81b5cbc`: `testsuite/lowrank/regress_vs_baseline.sh` prints IDENTICAL for **every** set in `SETS`.
- `Upgrade2` (`Prog/upgrade_mod.F90`) is not modified (except the existing `ALF_TRACE_UPDATES` block).
- Random numbers: exactly the draws of the standard path, in the same order (one Metropolis draw per Upgrade call).
- Tolerances: TOL_UNIT = 1e-10, TOL_ILL = 1e-8 (unit tier); statistical rules as pre-registered in `CLAUDE.md`.
- `N_P_LIM = 8`. **Capacity rule (D5, precise):** pending rank `p` per flavour (delayed: columns of X; submatrix: k = |S|
  incl. padded sites). Arrays are allocated for `max(N_delay, N_P_LIM)` (submatrix: `+ N_P_LIM` padding headroom; delayed
  also `≤ size(Op_V,1)*N_P_LIM`, submatrix also `≤ Ndim + N_P_LIM`). An accept that would add `r'` (delayed: r columns;
  submatrix: number of active sites not yet in S) flushes **first** if `p > 0 .and. p + r' > N_delay`; after any accept and
  after a hook's padding+transform, flush if `p ≥ N_delay`. Rank-1 behaviour is unchanged (N_delay = 1 flushes after every accept).
- No ZDOTU/ZDOTC (gfortran + Accelerate ABI); use `sum(a*b)`.
- Build: `source configure.sh GNU noMPI NO-INTERACTIVE >/dev/null 2>&1 && make all -j8` in one shell command; `/bin/rm`, not `rm`.
  ctest: `cd testsuite/tests && cmake .. && make -j8 && ctest -j8` (same shell, after sourcing configure.sh).
- After `make` with `ALF_FLAGS_EXT` (trace/debug builds) rebuild the normal binary and rerun `cmake ..` before `ctest`.
- Mac runs: ≤ 8 cores, anything > a few minutes in the background, each run < 2 h. Never read or touch `USER_TESTS/`.
- Commit after each passing task with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`; never push.

## Review Focus
1. A vertex with different structure per flavour (diagonal in one flavour and not in another; different `N_non_zero`,
   including 0 in one flavour) — per-flavour state must follow each flavour's own L/R and r. Pinned: unit case `asym_rn` (Task 2).
2. A vertex wrapped but not proposed (T0/`Propose_S0` reject) after a non-diagonal pending update — hooks must still be
   applied for both wraps. Pinned: unit case `bonds_skip` (Task 2).
3. `N_delay = 1` with rank-2/4 vertices — capacity rule must avoid overflow and flush correctly. Pinned: `N_DELAY_LIST`
   keeps 1 and gains 2 (Task 2).
4. Non-diagonal vertices in the ill-conditioned frame — the submatrix M-form error must stay ≤ TOL_ILL. Pinned: unit case
   `bonds_illcond` (Task 2).
5. A vertex with support N > 8 — must fall back (flush + Upgrade2) and say so once in `info`. Pinned: unit eligibility
   section `bigop` (Task 2) and the exact info string (Tasks 2–3).
