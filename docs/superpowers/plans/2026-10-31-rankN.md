# Rank-N delayed / general submatrix / projector / cross-slice / parallel validation — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Both low-rank schemes accelerate every vertex type ALF ships (rank-N, diagonal and non-diagonal), validated
at all tiers, plus projector validation, a cross-slice prototype and local parallel-mode validation (project 2,
Phases 3–5).

**Architecture:** All scheme logic stays in `Prog/Lowrank_update_mod.F90`; `Prog/Wrapgr_mod.F90` gains hook calls
around both wraps of every eligible vertex; `Upgrade2` and every default code path stay untouched. Formulas:
`docs/algorithm-notes.md` Part II; decisions D1–D12: the spec.

**Tech Stack:** Fortran 2008 (gfortran 16, `-O3 -ffast-math -fopenmp`), Accelerate BLAS/LAPACK, CMake/CTest,
bash + python3/numpy harnesses in `testsuite/lowrank/`.

**Spec:** `docs/superpowers/specs/2026-10-31-rankN-design.md`

## Global Constraints
- Default (`Sequential_scheme = "standard"`) byte-identical to baseline `f81b5cbc`: `testsuite/lowrank/regress_vs_baseline.sh` prints IDENTICAL for every set.
- `Upgrade2` (`Prog/upgrade_mod.F90`) is not modified (except the existing `ALF_TRACE_UPDATES` block).
- Random numbers: exactly the draws of the standard path, in the same order (one Metropolis draw per Upgrade call).
- Tolerances: TOL_UNIT = 1e-10, TOL_ILL = 1e-8 (unit tier); statistical rules as pre-registered in `CLAUDE.md`.
- `N_P_LIM = 8`; `cap = max(N_delay, N_P_LIM)`, delayed additionally `≤ size(Op_V,1)*N_P_LIM`, submatrix `≤ Ndim`.
- No ZDOTU/ZDOTC (gfortran + Accelerate ABI); use `sum(a*b)`.
- Build: `source configure.sh GNU noMPI NO-INTERACTIVE >/dev/null 2>&1 && make all -j8` in one shell command; `/bin/rm`, not `rm`.
- After `make` with `ALF_FLAGS_EXT` (trace/debug builds) rebuild the normal binary and rerun `cmake ..` before `ctest`.
- Mac runs: ≤ 8 cores, anything > a few minutes in the background, each run < 2 h. Never read or touch `USER_TESTS/`.
- Commit after each passing task with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`; never push.

## Review Focus
1. A vertex with different structure per flavour (diagonal in one flavour and not in another; different `N_non_zero`,
   including 0 in one flavour) — per-flavour state must follow each flavour's own L/R and r. Pinned: unit case `asym_rn` (Task 2).
2. A vertex wrapped but not proposed (T0/`Propose_S0` reject) after a non-diagonal pending update — hooks must still be
   applied for both wraps. Pinned: unit case `bonds_skip` (Task 2).
3. `N_delay = 1` with rank-2/4 vertices — capacity `max(N_delay, N_P_LIM)` must avoid overflow and flush correctly.
   Pinned: `N_DELAY_LIST` gains 2 and keeps 1 (Task 2).
4. Non-diagonal vertices in the ill-conditioned frame — explicit Γ̃^{-1} error must stay ≤ TOL_ILL. Pinned: unit case
   `bonds_illcond` (Task 2).
5. A vertex with support N > 8 — must fall back (flush + Upgrade2) and say so once in `info`. Pinned: unit case
   `bigop` (Task 2) checks `Lowrank_eligible = .false.` and agreement with the reference.
